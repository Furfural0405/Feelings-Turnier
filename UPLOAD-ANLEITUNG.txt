FEELINGS-TURNIER – ALLE TEILNEHMER GLEICHZEITIG LÖSCHEN

Bitte diese beiden Dateien in das GitHub-Repository kopieren bzw. ersetzen:

1) .github/workflows/apply-participant-clear.yml
2) scripts/apply_participant_clear.py

Danach auf main committen.

Der Workflow startet automatisch und:
- ergänzt im Teilnehmer-Adminbereich den Button „Alle Teilnehmer löschen“
- zeigt vor dem Löschen eine Sicherheitsabfrage
- löscht alle Teilnehmer aus Supabase
- setzt Gruppen, KDA-Werte und K.O.-Phase zurück
- behält Gruppenanzahl und eingestellte Gruppen-Rundenzahl bei
- baut die Webseite anschließend direkt neu
- deployed die gepatchte Version direkt auf GitHub Pages

WICHTIG:
Für den Workflow müssen unter GitHub > Settings > Actions > General > Workflow permissions
„Read and write permissions“ aktiviert sein.
