Was bereits LIVE in Supabase erledigt wurde:
- Edge Function "register-admin-request" ist ACTIVE.
- Edge Function "remove-rejected-admin-request" ist ACTIVE und verlangt einen gültigen Login/JWT.
- Neue Accounts werden serverseitig mit email_confirm=true angelegt.
- Dadurch wird bei der Registrierung KEINE Bestätigungs-Mail versendet.
- Der bestehende Passwort-Reset per E-Mail bleibt unverändert.

- Nur turnier.admin@gmx.de darf Freigaben verwalten (serverseitig abgesichert).

- Beim endgültigen Entfernen wird der Auth-Account gelöscht; das Profil verschwindet durch ON DELETE CASCADE.
- Die E-Mail-Adresse kann sich danach bei Bedarf erneut registrieren.
- Das Registrierungs-Rate-Limit bleibt aktiv: max. 3 Versuche pro E-Mail/60 Min. bzw. 8 pro IP/15 Min.

NEU · Twitch im Header
----------------------
- Der Twitch-Player im Header ist jetzt direkt auf der Webseite bedienbar.
- Play/Pause, Lautstärke und Vollbild laufen über den offiziellen interaktiven Twitch Player.
- Der Header erkennt über die offiziellen Player-Events ONLINE/OFFLINE, ob brumefeelings gerade live ist.
- Bei LIVE erscheint ein roter pulsierender Punkt und der Text LIVE.
- Bei OFFLINE erscheint ein grauer Punkt und OFFLINE.
- Während des Ladens wird LIVE-STATUS WIRD GEPRÜFT angezeigt.
- Falls Twitch den Status nicht liefern kann, wird STATUS NICHT VERFÜGBAR angezeigt.
- Der Player selbst ist nicht mehr komplett als Link überlagert; dadurch bleiben seine Bedienelemente klickbar.
- Über „Auf Twitch öffnen ↗“ bzw. den Kanalnamen kann jederzeit Twitch in einem neuen Tab geöffnet werden.
- Es ist KEIN Twitch Client Secret und KEIN Twitch API Token nötig.

Für diese Twitch-Änderung müssen in GitHub mindestens ersetzt werden:
- src/App.tsx
- src/styles.css

Supabase muss für die Twitch-Funktion NICHT verändert werden.

TWITCH QUALITÄT (NEU):
- Im Mini-Player gibt es jetzt eine Qualitätsauswahl für 360p, 480p, 720p und 1080p.
- Twitch entscheidet pro Live-Stream, welche Qualitätsstufen tatsächlich verfügbar sind.
- Nicht verfügbare Stufen werden im Auswahlfeld deaktiviert angezeigt.
- Die native Twitch-Qualitätsauswahl im Player bleibt ebenfalls vorhanden.
